Attorney Hub status by region

Each region rolls up every system we check from there. A region is down when any of its systems is down, and degraded when any is degraded. Its uptime counts each system's downtime separately, so it never overstates availability.

Sign-in is checked from a single location rather than from a region, so it is in no region below. Its status, and each system's history, is on the Status page.
